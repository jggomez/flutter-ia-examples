# Snap & Sell — Generative UI Marketplace Assistant

Snap & Sell is a generative UI marketplace assistant where a mobile seller takes or selects a photo of an item on a single entry screen, and a remote Python ADK agent powered by Gemini Vision dynamically generates every subsequent screen in the application. Built with Flutter GenUI, the A2UI protocol, and Google's Agent Development Kit on Cloud Run and Vertex AI, the app adapts its interface in real time to match whatever product the seller is listing.

Instead of forcing every seller through a rigid, one-size-fits-all form, the agent inspects the item photo, identifies the product category and visible attributes, and streams schema-validated UI surfaces that ask only the questions relevant to a car, motorcycle, or phone.

## Key Capabilities

- **Single-Screen Entry & Dynamic UI Generation**: The mobile client ships a single photo capture screen; every subsequent step in the selling journey is generated by the AI agent and rendered natively by Flutter GenUI.
- **Multimodal Vision & Category Adaptation**: Gemini Vision identifies the item category, brand, model, color, and condition from the uploaded photo, pre-filling known fields and tailoring follow-up inputs to that specific category.
- **Conditional Visual Verification**: When an item requires additional proof—such as a dashboard odometer photo for a vehicle or a close-up of visible wear—the agent dynamically inserts a photo capture card into the UI flow.
- **Automated Market Pricing & Listing Preview**: Once all item details are verified, the agent computes a recommended USD market price band and streams an interactive price slider alongside an editable listing preview.

## Generative UI & Agent Architecture

![A2UI Interaction Sequence](../../images/a2ui/a2ui-interaction-sequence.png)

### How the A2UI + ADK Pipeline Works

1. **Multimodal A2A Request**: The Flutter app captures a photo of the item and streams it over the Agent-to-Agent protocol along with the custom Snap & Sell component catalog declaration.
2. **Gemini Vision & Deterministic Marketplace Tools**: The Python ADK agent analyzes the photo with Gemini Vision and invokes structured tools to record detected item attributes, validate seller inputs, extract mileage from odometer photos, and compute market price ranges.
3. **Schema-Validated A2UI Surface Streaming**: The agent composes each screen using a shared custom component catalog—including `StepProgress`, `DetectedItemCard`, `PhotoRequest`, `PriceRange`, and `ListingPreview`—and validates every payload against the A2UI JSON Schema before streaming it to the client.
4. **Native Flutter GenUI Rendering**: Flutter GenUI renders the incoming surface definitions as native widgets with reactive two-way data binding between form fields and the agent session.

## Getting Started

```bash
# 1. Start the Python ADK agent locally or connect to the deployed Cloud Run service
cd apps/a2ui_snap_sell/agent
uv run uvicorn app.fast_api_app:app --host 0.0.0.0 --port 8000 --reload

# 2. Run the Flutter mobile client
cd apps/a2ui_snap_sell/mobile
flutter pub get
flutter run --dart-define-from-file=config/prod.json
```
